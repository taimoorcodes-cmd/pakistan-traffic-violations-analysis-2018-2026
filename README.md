
# Pakistan Traffic Challan Analysis

## Project Overview
End-to-end data analytics project analyzing
827,700 Pakistan traffic challan records
from 2018 to 2026 to identify revenue
leakage patterns, enforcement gaps, and
compliance failures across cities,
provinces, and vehicle categories.

## Tools Used
- Python (Pandas) - Data Cleaning
- MySQL - SQL Analysis (20 Queries)
- Power BI - Dashboard

## Dataset
- 827,700 rows
- 15 columns (after cleaning)
- Variables: City, Province, Violation Type,
  Vehicle Type, Fine Amount, Payment Status,
  Enforcement Method, Year, Month and more
- Timeline: 2018 to 2026

## Key Findings

1. Pakistan loses 682 Million PKR in
   uncollected fines nationally

2. Payment compliance rate locked at
   55% for 8 consecutive years despite
   136% growth in enforcement volume

3. Speeding generates 160 Million PKR
   in uncollected revenue alone

4. Karachi dominates 4 out of top 5
   cash leakage hotspots nationwide

5. Motorcycles are the highest risk
   vehicle class with 238 Million PKR
   in uncollected fines

6. Cameras detect 40% of violations
   but achieve same collection rate
   as physical officers

7. Q2 (April-June) is peak quarter
   for both violations and leakage

8. Punjab holds 117,211 unpaid tickets
   worth 322 Million PKR
